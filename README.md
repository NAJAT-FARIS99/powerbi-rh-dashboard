# Dashboard RH - Power BI

## Description
Ce projet consiste à analyser les données RH d’une entreprise afin de comprendre la répartition des effectifs, la masse salariale et les tendances démographiques.

##  Fonctionnalités
- Analyse des effectifs par service et pays
- Répartition des contrats (CDI, CDD, Intérim)
- Analyse de la masse salariale
- Répartition hommes / femmes
- Analyse par tranche d’âge et salaire
- Dashboard interactif avec filtres

##  Outils utilisés
- Power BI
- Power Query
- DAX
